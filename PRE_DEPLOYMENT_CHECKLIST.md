# FundingSathi CRM - Pre-Deployment Checklist

Use this checklist to ensure everything is ready before deployment.

---

## 📋 Pre-Deployment Verification

### ✓ GitHub Repository
- [ ] Repository is at: https://github.com/Preeti54444/CRM
- [ ] You have push access to the repository
- [ ] Latest code is committed and pushed:
  ```bash
  git status  # Should show "nothing to commit, working tree clean"
  git log --oneline -1  # Should show your latest commit
  ```

### ✓ Local Environment
- [ ] Git is installed (`git --version`)
- [ ] You can SSH to your VPS (`ssh user@your-vps-ip`)
- [ ] You have a text editor for configuration files

### ✓ Domain Setup
- [ ] You own or control a domain (e.g., fundingsathi.com)
- [ ] You can edit DNS records for your domain
- [ ] DNS A record is set to point to your VPS IP:
  ```
  api.YOUR-DOMAIN.com  A  YOUR_VPS_IP
  YOUR-DOMAIN.com      A  YOUR_VPS_IP
  ```

### ✓ VPS Preparation
- [ ] VPS is running (Ubuntu 20.04 or later recommended)
- [ ] You have SSH access as root or with sudo privileges
- [ ] VPS has at least 2GB RAM and 10GB disk space
- [ ] VPS has public internet access
- [ ] Port 80 and 443 are not blocked by firewall
- [ ] Port 22 (SSH) is open for your IP

### ✓ Vercel Account
- [ ] You have a Vercel account (https://vercel.com)
- [ ] Vercel is connected to your GitHub account

### ✓ Email Configuration
- [ ] You have Gmail account OR other SMTP provider
- [ ] If using Gmail:
  - [ ] Two-factor authentication is enabled
  - [ ] You've created an App Password (not your regular password)
  - [ ] You have the 16-character App Password ready

### ✓ Security Preparation
- [ ] You have a password manager or secure place for credentials
- [ ] You're ready to generate and store:
  - [ ] PostgreSQL password (strong, ≥16 chars)
  - [ ] SECRET_KEY (generated by script)
  - [ ] SMTP password (Gmail App Password)

## 🚀 Deployment Steps

### PHASE 1: Frontend on Vercel (5-10 minutes)

**Goal**: Deploy frontend to Vercel with automatic CI/CD

**Checklist**:
- [ ] Go to https://vercel.com/dashboard
- [ ] Click "Add New" → "Project"
- [ ] Select `Preeti54444/CRM` repository
- [ ] Set Root Directory to `frontend`
- [ ] Set Framework Preset to `Other`
- [ ] Set Build Command to empty
- [ ] Set Output Directory to `.`
- [ ] Set Install Command to empty
- [ ] Click "Deploy"
- [ ] Wait for deployment to complete (~2-3 minutes)
- [ ] Note the Vercel URL (e.g., https://fundingsathi-crm.vercel.app)
- [ ] In Project Settings → Environment Variables, add:
  - [ ] Name: `VITE_API_URL`
  - [ ] Value: `https://api.YOUR-DOMAIN.com`
  - [ ] Select Production environment
  - [ ] Save

**Verification**:
- [ ] Open https://your-vercel-app.vercel.app in browser
- [ ] Should see the login page
- [ ] Page loads without errors

---

### PHASE 2: Backend on VPS (30-60 minutes)

**Goal**: Deploy backend, database, and Nginx on your VPS

**Prerequisites**:
- [ ] Domain DNS is configured (A record pointing to VPS IP)
- [ ] SSH access to VPS is working
- [ ] You have your Vercel app URL from Phase 1
- [ ] You have database password, email credentials ready

**Steps**:

1. **SSH into VPS**:
   ```bash
   ssh root@your-vps-ip
   # Or:
   ssh -i /path/to/key.pem user@your-vps-ip
   ```
   - [ ] Successfully logged into VPS

2. **Run deployment script**:
   ```bash
   cd /tmp
   wget https://raw.githubusercontent.com/Preeti54444/CRM/master/deploy-vps.sh
   # OR clone the repo first:
   git clone https://github.com/Preeti54444/CRM.git
   cd CRM/FundingSathi-CRM-Clean
   
   bash deploy-vps.sh
   ```
   - [ ] Script execution started

3. **Answer prompts**:
   - [ ] Domain: `your-domain.com`
   - [ ] Vercel app URL: `your-app.vercel.app`
   - [ ] PostgreSQL password: `strong-password-16-chars`
   - [ ] SMTP email: `your-email@gmail.com`
   - [ ] SMTP app password: `Gmail-App-Password`

4. **Wait for completion**:
   - [ ] Docker installation (if needed)
   - [ ] Repository cloning
   - [ ] .env.prod creation
   - [ ] SSL certificate installation
   - [ ] Nginx configuration
   - [ ] Service startup (~2 minutes)

5. **Script completion**:
   - [ ] See message: "✓ DEPLOYMENT COMPLETE"
   - [ ] Note the URLs shown
   - [ ] Check that all services show "UP"

---

### PHASE 3: Verification (10-15 minutes)

**Goal**: Verify all components are working

**Backend Health Check**:

```bash
# From your VPS (or any computer with curl):
curl -k https://api.YOUR-DOMAIN.com/health
# Should return: {"status": "ok"}
```
- [ ] API responds with status ok

**Database Check**:

```bash
# On VPS:
docker-compose ps
# Should show:
# postgres - UP
# backend - UP
# frontend - UP
# nginx - UP
# redis - UP
```
- [ ] All services are UP

**Frontend CORS Check**:

```bash
# Open browser at: https://your-vercel-app.vercel.app
# Press F12 to open Developer Console
# In Console tab, paste:

fetch('https://api.YOUR-DOMAIN.com/health')
  .then(r => r.json())
  .then(d => console.log('✓ CORS OK:', d))
  .catch(e => console.error('✗ Error:', e))

# Should see: ✓ CORS OK: {status: 'ok'}
```
- [ ] CORS test passes

**Database Privacy Check**:

```bash
# From your local machine (NOT the VPS):
psql -h YOUR-VPS-IP -U postgres -d fundingsathicrm
# Should timeout or refuse connection
# This means database is NOT exposed to internet ✓
```
- [ ] Database is private (connection refused)

**Run Verification Script** (on VPS):

```bash
bash verify-deployment.sh YOUR-DOMAIN.com
# Should show multiple ✓ PASS results
```
- [ ] All verification tests pass

---

### PHASE 4: Test Data Flow (10-15 minutes)

**Goal**: Verify that data actually flows through the entire system

**Manual Test** (if you have test credentials):

1. **Open frontend**: https://your-vercel-app.vercel.app
2. **Log in** with test credentials
3. **Create a test record** (lead, contact, etc.)
4. **Verify it appears** in the list
5. **Refresh the page**
6. **Check that record still appears** (persistence check)

- [ ] Can log in
- [ ] Can create records
- [ ] Records appear immediately
- [ ] Records persist after page refresh

**Database Query Test** (on VPS):

```bash
docker-compose exec postgres psql -U postgres -d fundingsathicrm -c "\dt"
# Shows all tables
```

```bash
docker-compose exec postgres psql -U postgres -d fundingsathicrm -c "SELECT COUNT(*) FROM leads;"
# Shows count of leads (should match records created)
```

- [ ] Database tables exist
- [ ] Can query data from database

**Logs Check** (on VPS):

```bash
# Should show no errors
docker-compose logs backend | grep -i error
# If nothing shows up, all good ✓

# Check recent logs
docker-compose logs backend --tail=50
```

- [ ] No ERROR messages in logs
- [ ] See normal request/response logs

## 📊 Post-Deployment Checklist

After everything is deployed and tested:

### Documentation
- [ ] Note your Vercel URL
- [ ] Note your API URL
- [ ] Store credentials securely (password manager)
- [ ] Document your VPS IP, domain, SSH access method

### SSL Certificate
- [ ] Certificate installed and working:
  ```bash
  curl -I https://api.YOUR-DOMAIN.com  # Should show 200 OK
  ```
- [ ] Certificate auto-renewal is enabled:
  ```bash
  sudo systemctl status certbot.timer
  ```

### Backups & Security
- [ ] Database backup plan established
- [ ] .env.prod is NOT in Git
- [ ] Database credentials are stored securely
- [ ] SSH key is backed up

### Ongoing Operations
- [ ] You know how to:
  - [ ] View logs: `docker-compose logs -f`
  - [ ] Stop services: `docker-compose down`
  - [ ] Start services: `docker-compose -f docker-compose.prod.yml up -d`
  - [ ] Update backend: `bash update-backend.sh`

## 🔄 Deployment Workflow After Setup

### To Push Frontend Changes

```bash
# On your local machine:
git add .
git commit -m "Update frontend: your message"
git push origin master

# Vercel automatically detects and redeploys
# Monitor at: https://vercel.com/dashboard
```

- [ ] Code committed
- [ ] Pushed to GitHub
- [ ] Vercel starts deploying
- [ ] Frontend updates within 1-2 minutes

### To Push Backend Changes

```bash
# On your local machine:
git add .
git commit -m "Update backend: your message"
git push origin master

# Then on VPS:
ssh user@your-vps-ip
cd /opt/fundingsathi-crm/FundingSathi-CRM-Clean
bash update-backend.sh

# Or manually:
git pull origin master
docker-compose -f docker-compose.prod.yml down
docker-compose -f docker-compose.prod.yml up -d --build
```

- [ ] Code committed
- [ ] Pushed to GitHub
- [ ] SSH into VPS
- [ ] Pull latest and restart services
- [ ] Verify with: `docker-compose logs -f`
